# 전통시장 상인용 장부 앱 — QA 산출물

서울시 소상공인 매출증진 프로젝트에서 개발한 장부 앱의 품질 검증 산출물입니다.
앱 자체는 Claude(LLM)를 코딩 도구로 활용해 구현했고, 검증 기준 설계·테스트 케이스 작성·결함 발견 및 대응은 직접 수행했습니다.



## 구성

| 파일 | 내용 |
|---|---|
| `app.html` | 장부 앱 최종본 (단일 HTML, localStorage 저장) |
| `test_regression.py` | 자동 회귀 테스트 — 계산 정확도, 데이터 저장, 화면 이동, 렌더링 등 7개 영역 49건 |

## 테스트 실행

```bash
pip install playwright
playwright install chromium
python test_regression.py app.html
```

## 검증 설계 원칙

이 앱의 사용자는 장부를 쓸 동기도 습관도 없는 70대 소상공인입니다. 불편을 겪으면 참지 않고 그대로 이탈하며, 계산이 틀려도 대조할 원본 장부가 없어 오류를 스스로 알아챌 수 없습니다. 이에 따라 세 가지 원칙으로 검증했습니다.

1. 금액은 화면 표시 여부가 아니라 직접 계산한 기대값과 대조한다
2. 화면 표시는 스크린샷이 아니라 렌더링 결과를 실측한다
3. 저장 결과는 UI가 아니라 저장소 원본을 직접 확인한다

## 발견한 결함 (요약)

- **결제수단 비율 텍스트 글꼴 결함** — 지정값 17px, 실제 렌더링 22px. 전역 CSS 규칙이 개별 지정을 덮어쓰는 구조적 문제로, 5개 이상 화면에서 반복 발생해 사전 점검 체크리스트로 전환
- **화면(모달) 중첩 결함** — 특정 화면이 다른 화면 내부에 잘못 삽입되어 단독 접근 불가. 검증 절차를 도구화하는 과정에서 발견, 전체 화면 대상 전수 점검으로 확대
